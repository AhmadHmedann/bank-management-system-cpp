# Bank Client Management System (C++)

## Description
A console-based C++ application that manages bank client records using file-based storage.
The system supports full CRUD operations and basic banking transactions through a menu-driven interface.

## Features
- Add, update, delete, and find clients
- Prevent duplicate account numbers
- Deposit and withdraw funds
- Display total balance across all clients
- Persistent storage using file I/O

## Technologies & Concepts
- C++
- STL (vector, string)
- File I/O (fstream)
- Structs, enums, references
- CRUD design
- Console-based UI

## How It Works
Client records are stored in a text file and loaded into memory for processing.
All modifications are applied in memory and saved back to the file.

## Future Improvements
- Database integration
- Improved validation and error handling
- Transaction history
